2026-09-09. HEAD `4a440f3cd25ddeeab0d54e2ac466a33a62c1fdb8`, checkout com alterações anteriores das Fases 2/T3.1 preservadas. Nenhum commit criado.

## Implementação

- Vendor canônico 1.2.10 e licença Apache 2.0 copiados de `webos/hello/site` para `webos/lib/webOSTVjs-1.2.10`. Fixtures históricos intactos. `info.minimized` impede que o Terser altere os bytes já minificados do vendor validado.
- Webpack copia o vendor apenas para webOS. O carregamento condicional de `src/index.html` foi preservado, antes de main e worker.
- `usePlatform().webos` expõe exatamente `active`, `deviceInfo`, `platformBack`. Adaptador resolve os globais por operação, sem acesso nativo quando `WEBOS` está desabilitado. `active` indica presença de webOS ou PalmSystem no build habilitado; não garante sucesso de cada API.
- `webOS.deviceInfo(callback)` tem prioridade; somente sua ausência seleciona o JSON PalmSystem. Respostas vazias/inválidas, JSON malformado e exceções retornam null. Respostas parciais preservam campos válidos e usam null nos ausentes. Callback tardio após desmontagem não atualiza estado.
- `sdkVersion` usa somente o campo homônimo: `version` e `platformVersion` são firmware. O PalmSystem real do emulador não fornece SDK; seu fallback retorna modelo `webOS.TV` e SDK null.
- Back retorna true quando a chamada é delegada sem exceção, não como confirmação de navegação. Prefere webOS, usa PalmSystem se ausente ou falhar e retorna false se indisponível. `/debug` inspeciona disponibilidade sem executar Back.
- Sem handler 461, eventos de ciclo de vida, webOSDev ou mudanças no player/core.

### Limitação separada

O app completo packaged continua com o bloqueio previamente documentado de fetch do WASM via `file://`, que impede o bootstrap do core e a renderização do contexto. Esta tarefa valida o vendor pelo fixture e não afirma smoke do contexto no app completo packaged. Evidência anterior: [T3.1](T3.1%20-%20Evidências.md), [erros](t31-runtime-packaged.json). Nenhum workaround de WASM foi introduzido. Back foi inspecionado no emulador e sua delegação testada por mocks; o smoke não navega para fora do app. TV física fora desta validação.
